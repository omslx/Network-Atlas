# 🌐 Network-Atlas

**Network-Atlas** is a lightweight, extensible packet testing and network experimentation tool written in Go.

It provides a simple command-line interface for sending and receiving UDP packets while exposing useful packet information directly in the terminal.

---

## ✨ Features

* 📤 UDP packet sending
* 📥 UDP packet receiving
* 🔧 Configurable source and destination addresses
* 🎯 Configurable destination port
* 🔢 Configurable packet count
* ⏱️ Configurable sending interval
* 🖥️ Real-time terminal output
* 🧩 Clean and modular Go architecture
* ⚡ Lightweight and fast

## 🚀 Build

Build Network-Atlas with:

```bash
go build -o network-atlas ./cmd/network-atlas
```

Then check the available options:

```bash
sudo ./network-atlas -h
```

---

# 📤 Sending Packets

Use `-c` to start the packet sender:

```bash
sudo ./network-atlas -c
```

You can customize the parameters:

```bash
sudo ./network-atlas \
    -c \
    -src <source-ip> \
    -dst <destination-ip> \
    -port <port> \
    -count <amount> \
    -interval <milliseconds>
```

### Example

```bash
sudo ./network-atlas \
    -c \
    -src <source-ip> \
    -dst <destination-ip> \
    -port 9999 \
    -count 20 \
    -interval 100
```

Example output:

```text
[01] <source-ip> -> <destination-ip>:9999  SUCCESS
[02] <source-ip> -> <destination-ip>:9999  SUCCESS
[03] <source-ip> -> <destination-ip>:9999  SUCCESS
...
[20] <source-ip> -> <destination-ip>:9999  SUCCESS

Done! 20 packets processed.
```

---

# 📥 Receiving Packets

Use `-s` to start the packet receiver:

```bash
sudo ./network-atlas -s -port 9999
```

Network-Atlas will listen for UDP packets and display information about received traffic.

Example:

```text
Listening for UDP packets on port 9999...

[RECV] <source-ip>:40000 -> <destination-ip>:9999  SUCCESS
       Payload: hello from Network-Atlas
```

# 🧰 Command-Line Options

|    Option   | Description                |    Default   |
| :---------: | -------------------------- | :----------: |
|     `-c`    | Send packets               |    `false`   |
|     `-s`    | Receive packets            |    `false`   |
|    `-src`   | Source IP address          | `127.0.0.50` |
|    `-dst`   | Destination IP address     |  `127.0.0.1` |
|   `-port`   | UDP destination port       |    `9999`    |
|   `-count`  | Number of packets to send  |     `10`     |
| `-interval` | Delay between packets (ms) |     `100`    |

---

# 🔬 Packet Inspection

Network-Atlas can be used alongside packet inspection tools such as `tcpdump` to verify network traffic independently.

For example:

```bash
sudo tcpdump -ni any udp port 9999
```

This can help determine whether packets generated by Network-Atlas are actually reaching the expected interface.

# 🧠 Architecture

Network-Atlas follows a simple modular architecture:

```text
                 Network-Atlas
                       │
                ┌──────┴──────┐
                │             │
             Sender        Receiver
                │             │
                ▼             ▼
             Packets       Packets
                │             │
                └──────┬──────┘
                       │
                  Network Layer
```

The separation between the sender and receiver makes the project easy to extend with additional protocols, packet types, filters, and analysis functionality.
